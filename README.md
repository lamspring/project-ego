# PROJECT EGO

### 自主价值演化智能体 · Autonomous Value-Evolution Agent

**EXPERIENCE · REFLECTION · VALUE · EVOLUTION**

> 不预设 Agent 最终应该成为什么样的个体。
> 我们负责创造成长机制，而不是编写成长的终点。

---

一个关于"AI如何形成自己的价值观"的开放研究项目。

- 📐 [THEORY.md](./THEORY.md) —— 理论：核心闭环、六原则、涌现原则、集体经验引擎、文明演化循环
- 🔧 [TASKBOOK.md](./TASKBOOK.md) —— 工程：数据Schema、模块实现、节拍配置、M1-M6里程碑、验收标准

**核心命题**：从"给 Agent 预先编写人格"，转向"设计一个能逐渐形成自己人格的系统"。

```
经历 → 比较 → 复盘 → 认知更新 → 价值演化 → 趋向 → 行动
  ↑                                                      |
  └──────────────────── 持续循环 ──────────────────────────┘
```

## 项目宪章

开发过程中始终保留一个问题：

> **我们究竟是在让它成为我们想象中的个体，还是在观察它最终会成为怎样的个体？**

希望答案永远是后者。
